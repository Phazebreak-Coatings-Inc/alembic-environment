# alembic-environment

Check the documentation [here](https://phazebreak-coatings-inc.github.io/alembic-environment/).

# Development

Files copied into user projects live in `template/`.

The CLI in `src/` is generated by [copier-template](https://github.com/Phazebreak-Coatings-Inc/copier-template). Pull its changes with `uvx copier-template update`.

Regenerate `example/` with `uv run alembic-environment example`.
